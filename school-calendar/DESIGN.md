# 브리티 메신저 캘린더 화면 기준

브리티 메신저 캘린더의 목록, 달력, 자세히 및 설정의 화면 기준이다.

왼쪽 목록, 가운데 월 달력, 오른쪽 **자세히** 세 칸이다. 왼쪽 2×2 탭은 **할 일**, **분류할 것**, **확인할 것**, **끝낸 것**이고 아래에 **숨기기**를 둔다. 할 일은 지남·오늘·이번 주·다음 주·그 뒤·날짜 없음으로 묶는다. 1180px 미만에서는 자세히를 오른쪽에서 덮어 나오게, 760px 미만에서는 한 줄로 쌓는다.

화면의 유형 이름은 할 일 / 확인할 것 / 숨기기다. 쪽지 한 건에 날짜 0~3개를 붙이고 날짜마다 짧은 이름과 **까지**(□, 날짜마다 끝냄 체크) 또는 **그날**(●)을 표시한다. 확인할 것은 기호 없이 흐린 글자로 보인다. 답장 단추는 쪽지 원문 제목 옆에 둔다.

달력 칸에는 날짜의 이름이 뜬다. ● → □ → 확인할 것 순으로 최대 3개, 두 줄, 넘치면 +N, 쪽지 제목은 마우스를 올리면 보인다. 날짜가 둘 이상인 쪽지는 각 칸에 따로 뜨고 잇는 선은 긋지 않으며, 고르면 같은 쪽지의 날짜가 모두 검은 테두리가 된다. 끝낸 □는 흐리게 줄을 긋고 지나간 ●는 흐리게만 한다. 받은 날~마감 사이는 칠하지 않고, 업무를 고르면 받은 날 칸에 "받음" 표시만 붙인다(2026-11-11 사용자 "노란박스 채워지는거 헷갈리겠는걸"). 숨긴 쪽지는 달력에서 제외한다.

날짜 묶음은 날짜 이름과 짧은 날짜를 한 줄에 표시한다. 남은 업무가 없는 지난 쪽지·대화 일정과 **다 봄**을 누른 참고 쪽지는 **끝낸 것**에 둔다. 탭에는 전체 건수와 빨간 점이 붙은 안 읽은 건수를 표시한다. 날짜가 여러 개인 쪽지는 안 읽은 건수에 한 번만 센다. 원문을 열면 굵은 제목과 빨간 점이 사라진다. 선생님이 유형이나 날짜를 고치면 AI의 원래 답과 함께 저장한다(`correction`).

교무실 탁상달력·업무 수첩처럼 보이게 한다. 종이색 바탕, 먹색 글자, 가는 괘선, 모서리 직각, 그림자·그라데이션·이모지·장식 아이콘 없음. 색은 뜻이 있을 때만: 빨강 = 일요일·마감 지남·확인 필요, 파랑 = 토요일, 노랑 = 오늘만. 월 숫자만 바탕체, 나머지는 맑은 고딕, 숫자는 고정폭. 정리 구역의 이름은 **AI 정리**다.

## 목록과 달력

- 왼쪽 목록의 기본 폭은 240px이다. 목록·자세히는 경계를 끌거나 키보드로 조절한다. 경계를 두 번 누르면 기본 폭으로 돌아간다.
- 업무나 원문을 열 때 자세히가 나타난다. 자세히를 닫으면 달력이 그 폭을 사용한다.
- 기간은 시작일부터 끝일까지 색 띠로 표시한다. 목록에는 시작일과 끝일을 짧게 보여 준다.

## 자세히

- 위쪽에 할 일·확인할 것·숨기기와 중요·상시·끝냄을 둔다. 끝낸 일은 같은 자리에서 다시 연다.
- 원문에는 수신인 수와 확보된 이름을 표시한다. 첨부는 원문 바로 아래에 둔다.
- 업무 편집에서 제목과 날짜를 따로 고치고 취소할 수 있다. 메모는 바로 쓴다.
- 쪽지를 숨겨도 저장된 날짜와 마감 완료 상태를 보존한다. AI 다듬기는 선택 사항이다.

## 분류할 것

- 분류 확인이 필요한 쪽지와 정리가 남은 대화방 수를 따로 표시한다.
- 대화 후보는 추천 유형으로 올리거나 다른 유형을 고르거나 버린다. 변경·취소 후보는 적용할 기존 업무를 고른다.
- 한 글에 번호나 줄표로 시작하는 항목이 다섯 줄 이상이면 전달 글로 표시한다. 원문 줄은 자세히에서 직접 올릴 수 있다. 동일한 줄을 다시 고르면 연결된 업무를 연다.
- 정리 끝을 누르면 현재 묶음 확인을 마친다. 남은 후보를 버리기 전에는 확인한다.

## 가져오기

- 첫 쪽지 가져오기는 기간과 예상 건수를 확인하고 이후 자동 갱신 또는 수동 가져오기를 선택한다.
- 설정의 가져올 대화방은 접힌 상태에서 선택 개수를 표시한다. 펼치면 방을 체크해 저장한다. 대화방 자동 갱신은 저장한 방에 적용한다.
- 대화방 선택 아래에 마지막 확인 시각과 새 글 수 또는 대기 이유를 표시한다.
- PC에 저장된 쪽지와 대화는 설정의 저장된 자료 다시 읽기에서 갱신한다.
