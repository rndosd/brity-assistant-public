# 브리티 메신저 캘린더 화면 기준

브리티 메신저 캘린더의 목록, 달력, 자세히 및 설정의 화면 기준이다.

왼쪽 목록, 가운데 월 달력, 오른쪽 **자세히** 세 칸이다. 왼쪽 2×2 탭은 **할 일**, **분류할 것**, **확인할 것**, **끝낸 것**이고 아래에 **숨기기**를 둔다. 할 일은 지남·오늘·이번 주·다음 주·그 뒤·날짜 없음으로 묶는다. 1180px 미만에서는 자세히를 오른쪽에서 덮어 나오게, 760px 미만에서는 한 줄로 쌓는다.

화면의 유형 이름은 할 일 / 확인할 것 / 숨기기다. 쪽지 한 건에 날짜 0~3개를 붙이고 날짜마다 짧은 이름과 **까지**(□, 날짜마다 끝냄 체크) 또는 **그날**(●, 화면 이름은 "일정")을 표시한다. 확인할 것은 기호 없이 흐린 글자로 보인다. 답장 단추는 쪽지 원문 제목 옆에 둔다.

달력 칸에는 날짜의 이름이 뜬다. ● → □ → 확인할 것 순으로 최대 3개, 두 줄, 넘치면 +N, 쪽지 제목은 마우스를 올리면 보인다. 날짜가 둘 이상인 쪽지는 각 칸에 따로 뜨고 잇는 선은 긋지 않으며, 고르면 같은 쪽지의 날짜가 모두 검은 테두리가 된다. 끝낸 □는 흐리게 줄을 긋고 지나간 ●는 흐리게만 한다. 받은 날~마감 사이는 칠하지 않고, 업무를 고르면 받은 날 칸에 "받음" 표시만 붙인다(2026-11-11 사용자 "노란박스 채워지는거 헷갈리겠는걸"). 숨긴 쪽지는 달력에서 제외한다.

날짜 묶음은 날짜 이름과 짧은 날짜를 한 줄에 표시한다. 남은 업무가 없는 지난 쪽지·대화 일정과 **다 봄**을 누른 참고 쪽지는 **끝낸 것**에 둔다. 탭에는 전체 건수와 빨간 점이 붙은 안 읽은 건수를 표시한다. 날짜가 여러 개인 쪽지는 안 읽은 건수에 한 번만 센다. 원문을 열면 굵은 제목과 빨간 점이 사라진다. 선생님이 유형이나 날짜를 고치면 AI의 원래 답과 함께 저장한다(`correction`).

교무실 탁상달력·업무 수첩처럼 보이게 한다. 종이색 바탕, 먹색 글자, 가는 괘선, 모서리 직각, 그림자·그라데이션·이모지·장식 아이콘 없음. 색은 뜻이 있을 때만: 빨강 = 일요일·마감 지남·확인 필요, 파랑 = 토요일, 노랑 = 오늘만. 월 숫자만 바탕체, 나머지는 맑은 고딕, 숫자는 고정폭. 정리 구역의 이름은 **AI 정리**다.

## 대화방 전달 글을 후보함에서 확인하기

2026-11-12 승인 및 앱 구현. 모델이 후보를 못 냈거나 분석에 실패해도 선생님이 감지된 전달 글에서 필요한 줄을 찾아 올릴 수 있게 한다. 라3b 두 시험은 미달로 종료하고 기존 대화방 시험 지침을 채택한다.

### 전달 글 판별과 후보 생성

- 새 대화 묶음의 글을 하나씩 검사한다. 한 글에 `1.`, `1)`, `①`, `-`, `•`처럼 줄 맨 앞에 번호나 줄표가 붙고 본문이 있는 줄이 5개 이상이면 전달 글로 본다. 들여쓰기는 허용한다. 줄바꿈은 원문 기준으로 세며, 여러 글의 줄 수를 합산하거나 화면에서 자동으로 꺾인 줄을 세지 않는다. 라3b 표본 준비에서 사용한 줄머리 판별식을 출발점으로 삼는다.
- 대화방 AI를 연결할 때는 앞선 라3 시험의 지침과 후보 형식(`.qa/chat-trial/실제/라3-실행.cjs`의 `rules`, `schema`)을 사용한다. 현재 앱의 대화방 후보 생성은 `chat-decisions.js`의 PC 규칙을 사용한다. 전달 글 표시와 수동 등록은 이 규칙으로도 구현하고 검증할 수 있다. 팩트챗 출력 한도는 현재 설정인 6,144토큰을 사용한다.
- 기존 후보의 근거는 글 단위다. 후보가 글을 인용했다는 이유로 그 글의 개별 줄을 처리된 것으로 판단하면 빠진 안건도 숨겨진다. 펼친 목록에는 원문 항목을 순서대로 모두 보여 주고, 이미 사람이 올린 줄에는 처리 상태를 표시한다. 줄표 없는 앞말·뒷말도 같은 글의 원문에서 확인할 수 있다. 안건에 이어지는 설명은 원래 항목과 함께 보여 준다.

### 분류할 것 화면과 등록

- 후보는 추천 유형을 쓴 올리기 버튼 하나와 다른 유형, 개별 버리기를 보여 준다. 변경·취소 후보는 **기존 업무 고치기**를 누르고 대상 업무를 고른다. 짝이 된 업무를 후보 아래에 표시한다.
- 묶음 아래에서 **원문 N줄 보기**를 누르면 오른쪽 자세히에서 전달 글의 줄을 고른다. 후보가 없거나 분석에 실패해도 확인할 원문이 있으면 묶음은 목록에 남는다. 탭에는 정리가 남은 방을 한 번씩 센다.
- 고른 줄은 제목 초안으로 보인다. 선생님이 제목·날짜·유형을 확인해 올린다. **정리 끝**은 이 묶음의 원문 확인을 마치고, 남은 후보가 있다면 한 번 확인한 뒤 버린다. 다른 묶음은 그대로 둔다. 버린 후보는 **숨긴 것**에서 되살리고, 등록한 업무에서는 원문 줄을 다시 열 수 있다.
- 수동 등록은 묶음 ID·글 위치·원문 시작 줄을 출처로 저장한다. 원문 확인 상태와 등록 출처는 재실행 뒤에도 남긴다. 같은 줄을 다시 누르면 이미 연결된 업무를 열며, 저장 도중 반복 입력이 들어와도 같은 줄의 업무를 한 번만 만든다. 이미 저장된 묶음의 원문을 읽을 수 있으면 같은 방식으로 표시한다.
