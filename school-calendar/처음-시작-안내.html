브리티 쪽지를 가져와 AI가 날짜와 할 일을 뽑아 달력에 올려 주는 앱입니다. 처음 한 번, 아래 순서대로 설정하면 됩니다. 15분 정도 걸립니다.

0먼저 알아 두기

순서
AI를 먼저 연결하세요. AI 없이 브리티부터 연결하면 쪽지가 날짜 없이 제목 그대로 할 일에 쌓입니다. 나중에 AI를 연결해 한꺼번에 정리할 수는 있습니다.
준비물
브리티 메신저가 설치돼 로그인할 수 있는 PC, 그리고 아래 AI 연결 방식 가운데 하나
자료 위치
가져온 쪽지와 업무는 이 PC의 캘린더 폴더 안에만 저장됩니다.

1AI 연결

처음 켜면 위쪽에 1단계 · AI 연결이 보입니다. AI 연결을 누르면 설정 → AI 연결 탭이 열립니다.

어떤 방식을 고를까요

연결 방식이런 분께안내서
개인 OpenAI API 키 · Luna (권장)처음이라 무엇을 고를지 모르겠다면 이것. 쓴 만큼 OpenAI 계정에 청구됩니다.OpenAI 연결 안내
개인 Claude API 키 · HaikuAnthropic(Claude) 개발자 계정을 쓰고 싶을 때. 쓴 만큼 그 계정에 청구됩니다.Claude API 연결 안내
Claude Code CLI · Haiku이미 Claude 구독(Pro 이상)을 쓰고 있을 때. 따로 청구되지 않습니다.Claude 구독 연결 안내
Codex CLI이미 ChatGPT 구독을 쓰고 있을 때. 따로 청구되지 않습니다.Codex 연결 안내

학교나 기관에서 따로 안내받은 연결 방식이 있으면 그것을 고르세요.

모델 · 쪽지 정리에는 Luna(OpenAI)·Haiku(Claude)를 씁니다. 이 앱이 시험을 마친 모델이고, 쪽지마다 부르기 때문에 비용을 낮추려고 고정해 두었습니다. Codex는 ChatGPT 계정의 기본 모델로 돌아 이보다 상위 모델이 쓰일 수 있고, 그만큼 구독 한도가 더 빨리 줄 수 있습니다.

연결하기

  1. AI 연결 방식에서 하나를 고릅니다.
  2. API 키 방식이면 처음 설정 안내 ↗를 눌러 가입·결제·키 만들기 순서를 따라 합니다. API 키 발급 ↗은 키를 만드는 화면을 바로 엽니다.
  3. 만든 키를 키 칸에 붙여 넣고(Ctrl+V) 연결 시험 및 저장을 누릅니다. 가짜 쪽지 한 건으로 시험합니다.
  4. 연결 시험을 통과했습니다가 나오면 끝입니다. 새 쪽지 자동 분류도 함께 켜집니다. 설정을 닫으세요.

AI가 읽는 것 · 쪽지를 정리할 때 고른 AI가 쪽지 본문을 읽고 날짜와 할 일을 뽑습니다. API 키 방식(OpenAI·Claude)으로 보낸 내용은 AI 학습에 쓰이지 않고, 구독 방식은 그 계정의 데이터 설정을 따릅니다. 쪽지를 자동으로 정리할 때는 첨부를 보내지 않습니다.

2브리티 연결

AI를 연결하면 위쪽이 2단계 · 브리티 연결로 바뀝니다.

  1. 브리티 메신저를 열고 로그인한 뒤, 브리티 창을 띄워 둡니다.
  2. 브리티는 원 뷰로 써 주세요. 클래식 뷰에서는 쪽지를 놓칠 수 있습니다. 브리티 환경설정 › 일반 › 뷰 모드에서 바꿉니다.
  3. 캘린더 위쪽 브리티 연결을 누릅니다.
  4. 첫 쪽지 가져오기 창이 열리고 브리티 쪽지 목록에 연결합니다.

가져온 쪽지는 브리티에서 읽음 처리됩니다.

3첫 쪽지 가져오기

지난 쪽지 불러오기 (선택)

  1. 시작일과 끝일을 고릅니다. 처음에는 최근 1주일로 채워져 있습니다.
  2. 불러오기를 누르면 가져옵니다. 기간을 길게 잡았다면 먼저 몇 건인지 보기로 건수를 미리 볼 수 있습니다(꼭 하지 않아도 됩니다).
  3. 불러오는 동안 브리티의 쪽지 목록이 저절로 움직입니다. 끝날 때까지 브리티 창은 건드리지 마세요. 쪽지가 많으면 몇 분 걸립니다.

앞으로 쪽지 가져오기

  • 자동으로 가져오기: 캘린더가 켜져 있는 동안 정해진 간격(처음에는 1시간)마다 새 쪽지를 가져옵니다.
  • 누를 때만 가져오기: 위쪽 쪽지 가져오기를 누를 때만 가져옵니다.

고른 뒤 기간 가져오기 건너뛰기(지난 쪽지를 불러왔다면 설정 마치기)를 누르면 설정이 끝납니다.

4매일 쓰기

첨부 요약쪽지 자세히에서 첨부 옆 요약을 누르면 .hwpx, .xlsx, .pptx와 글을 선택할 수 있는 PDF의 파일별 요지가 펼쳐집니다. 자세히에서 문서에 적힌 대상·요청·기한과 원문 근거를 확인하세요. 새로 요약할 때는 쪽지 본문과 첨부에서 읽은 글·표가 연결된 AI로 전달됩니다.
할 일해야 할 업무. 마감이 가까운 순서로 묶여 있고, 날짜가 있으면 달력에도 올라갑니다. 다 했으면 앞의 네모를 누릅니다.
분류할 것AI가 애매하다고 본 쪽지와 대화방에서 찾은 후보. 하나씩 보고 올리거나 버립니다.
확인할 것할 일은 아니지만 알아 둘 쪽지.
처리한 것 · 다른 메시지완료한 업무와 확인한 공지는 ‘처리한 것’에 모입니다. 감사나 확인 답장은 ‘다른 메시지’에서 다시 읽을 수 있습니다.
  • 업무를 누르면 달력 위에 자세히가 열립니다. 날짜·분류를 고치거나 쪽지 원문과 첨부를 볼 수 있습니다.
  • AI가 잘못 뽑았으면 고치기로 직접 고치거나 다듬기로 다시 정리합니다.
  • 쪽지가 아닌 일은 위쪽 업무 추가나 날짜 칸의 +로 직접 넣습니다.

수업 달력에서 시간표를 가져오거나 AI 박스로 받은 업무를 등록하는 방법은 앱 위쪽의 설명서에서 확인하세요.

5편하게 쓰기

  • 설정 → 백업·정보에서 컴퓨터를 켜면 자동으로 실행을 켜면 켤 때마다 캘린더가 저절로 열립니다.
  • 같은 탭에서 바탕 화면에 바로 가기를 만들 수 있습니다.
  • 설정 → 화면에서 스킨과 글꼴을, 위쪽 가 단추로 글자 크기를 바꿀 수 있습니다.
  • 불편한 점이나 바라는 기능은 위쪽 의견으로 보내 주세요. 쪽지와 업무 내용은 보내지 않습니다.

?안 될 때

브리티 메신저를 열고 로그인한 뒤 연결해 주세요브리티가 꺼져 있거나 로그인 전입니다. 브리티를 열고 로그인한 뒤 브리티 연결 다시 확인을 누르세요.
브리티 쪽지 화면을 읽지 못했습니다브리티 창에 메뉴(오른쪽 클릭 메뉴 등)가 열려 있으면 Esc로 닫고 다시 누르세요.
목록 위 AI 연결 전입니다1단계를 아직 하지 않았습니다. AI 연결하기를 누르세요.
목록 위 아직 정리되지 않았습니다AI를 연결하기 전에 가져온 쪽지입니다. AI로 정리를 누르면 한꺼번에 정리합니다. 손으로 고치거나 끝낸 쪽지는 건드리지 않습니다.
AI 연결 시험이 실패할 때고른 방식의 안내서 맨 아래 “안 될 때”를 보세요. 키를 일부만 복사했거나 결제·잔액이 없는 경우가 가장 많습니다.

그래도 안 되면 위쪽 의견으로 어떤 화면에서 막혔는지 알려 주세요.
