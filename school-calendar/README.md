## 실행

Windows에서 **[start-calendar.cmd](start-calendar.cmd)**를 실행한다. 새로 내려받은 폴더라면 이 폴더에서 Node.js 22.12 이상으로 다음 명령을 먼저 실행한다.

```powershell
npm ci
npm start
```

가상 데이터로 둘러보려면 **[start-calendar-demo.cmd](start-calendar-demo.cmd)**를 실행한다. **학급 임원 선거 결과**를 누르면 회신, 이전 안내, 첨부를 볼 수 있다. 샘플은 실제 업무와 분리해 저장하며 자동 분류는 꺼져 있다.

다음 배포용 ZIP에서는 압축을 풀고 `Brity Messenger Calendar.exe`를 연다. 브리티에 로그인한 뒤 **브리티 연결**을 누르면 첫 가져오기 창이 열린다. 시작일과 끝일을 고르고 **몇 건인지 보기**로 가져올 수 있는 쪽지를 확인한다. 기간 가져오기를 건너뛸 수도 있다. 앞으로는 자동 갱신이나 수동 가져오기를 고른다. 수동에서는 위쪽의 **쪽지 가져오기**를 누를 때 브리티를 확인한다. 이미 실행 중인 수집기가 있으면 그 저장 결과를 읽는다. 연결 방법과 오류 안내는 **[AI-SETUP.txt](AI-SETUP.txt)**에 있다.

왼쪽 **할 일**에는 남은 마감(□)과 그날 일정(●)이 날짜별로 모인다. 날짜를 붙이지 않은 할 일은 **날짜 없음**에 보인다. 다듬기는 선택이며 실패해도 쪽지의 분류는 유지된다. □를 눌러 마감을 끝낼 수 있다. 완료한 업무, 지난 쪽지·대화 일정, **다 봄**을 누른 참고 쪽지는 **끝낸 것**에서 다시 볼 수 있다.

**분류할 것**에서 쪽지의 분류·날짜·원문을 확인하거나 대화 후보를 **할 일**이나 **확인할 것**으로 올린다. 쪽지는 한 건씩, 대화방은 정리할 묶음이 남은 방을 한 번씩 센다. 달력 양옆 경계를 끌면 목록과 자세히 너비를 각각 바꿀 수 있다. 경계에 키보드 초점을 두고 좌우 방향키로 조절할 수 있으며, 두 번 누르면 기본 너비로 돌아간다.

**할 일**, **확인할 것**, **끝낸 것**, **숨기기**는 각각 전체 건수와 안 읽은 건수를 보여 준다. 안 읽은 쪽지는 굵은 제목과 빨간 점으로 표시한다. 원문을 열면 읽음으로 저장된다. **숨기기**에는 감사·확인 답장처럼 할 일이 없다고 분류한 쪽지와 목록에 연결된 업무가 없는 대화 묶음이 보인다. 숨긴 쪽지를 열고 분류에서 **할 일** 또는 **확인할 것**을 고르면 되돌릴 수 있다. 숨기기 전에 저장한 날짜와 마감 완료 표시는 되돌렸을 때 다시 나타난다.

확인된 쪽지 원문의 **브리티에서 답장**을 누르면 현재 쪽지 목록에서 같은 쪽지를 찾아 브리티 답장창을 연다. 받는 사람과 내용을 확인하고 브리티에서 보낸다. 브리티 창이 뒤에 있으면 작업 표시줄에서 선택한다. 목록에 쪽지가 없으면 상세에 표시된 보낸 사람과 받은 시각으로 찾을 수 있다.

날짜 칸을 눌러 업무를 직접 추가한다. 오른쪽 자세히의 **할 일·확인할 것·숨기기**로 분류하고, 옆의 **중요·상시·끝냄**을 누른다. 끝낸 업무는 같은 자리에서 **다시 열기**로 되돌린다. 업무 제목과 날짜는 각각 **고치기**를 눌러 수정하고, 메모는 바로 쓴다. 첨부는 원문 바로 아래에 있고 **AI 정리**의 **다듬기**는 쪽지를 바탕으로 제목, 기한, 분류, 정리를 채운다.

위쪽 **쪽지 가져오기**는 브리티에서 쪽지를 가져온다. PC에 저장된 쪽지와 대화를 다시 읽으려면 설정에서 **저장된 자료 다시 읽기**를 누른다.

쪽지 업무를 고르면 달력의 받은 날 칸에 **받음**이 붙는다. 화면 기준은 [DESIGN.md](DESIGN.md).

**지시문 복사**를 누르고 Claude나 ChatGPT 채팅에 붙여 넣는다. 지시문에는 업무 제목, 기한, 기존 정리, 쪽지 내용이 들어간다. 전달 쪽지는 회신과 이전 안내 본문만 담고, 필요한 첨부는 채팅에서 직접 추가한다.

## 브리티 대화방 새 글

설정의 **자동 갱신**에서 쪽지와 대화방을 따로 켜고 주기(5·10·30분, 1·2시간)를 고릅니다. 기본은 둘 다 켜짐·1시간입니다. 연결한 뒤 머리줄의 **쪽지 가져오기**를 누르면 언제든 바로 가져오고, 자동 분류가 꺼져 있어도 이렇게 가져온 쪽지는 분류합니다. 브리티를 쓰는 중(브리티 창이 맨 앞)이면 가져오지 않고 묻습니다. 버튼으로 가져올 때는 캘린더 창에서, 자동 갱신 때는 Windows 알림으로 묻고, 알림을 누르지 않으면 다음 주기에 다시 봅니다. 대화방은 브리티 창이 최소화돼 있을 때 **전체** 탭을 확인합니다. 수집할 때 브리티의 읽음 표시가 바뀔 수 있습니다.

**가져올 대화방**을 펼치고 **방 목록 불러오기**를 누릅니다. 가져올 방을 체크한 뒤 **선택 저장**을 누르면 대화방 자동 갱신 때 그 방만 엽니다. 처음에는 선택한 방이 없습니다. 브리티 목록에서 방 이름이나 인원 표시가 바뀌면 목록을 다시 불러와 그 방을 고르세요.

설정의 대화방 선택 아래에는 마지막 확인 시각과 새 글 수, 또는 브리티 창 최소화 대기 등 가져오지 못한 이유가 표시됩니다.

쪽지 목록이 열려 있으면 현재 목록을 읽습니다. 목록을 찾지 못한 경우에만 쪽지 메뉴를 열며, 이때 잠깐 브리티로 포커스가 이동할 수 있습니다.

각 방을 처음 발견하면 이미 로딩된 글의 순서를 기준으로 기록합니다. 이후 기준과 겹치는 부분을 찾아 그 뒤의 새 글만 `data/chats`의 방별 JSON에 저장합니다. 방 제목이 달라지면 새 기준을 잡습니다. 제목이 같아 방을 구분할 수 없거나 이전 글과 겹치는 부분을 확인할 수 없으면 해당 방의 저장을 보류합니다. 최근 확인 결과와 검토가 필요한 방의 수는 `data/chats/status.json`에 있습니다.

방마다 첫 새 글이 들어오면 5분 동안 글을 모읍니다. 그 뒤 같은 방에서 이전 24시간 동안 수집한 글을 최대 30개까지 함께 읽습니다. 할 일, 확정 일정과 변경·취소를 **할 일**에 표시하며, 날짜가 있는 항목은 월 달력에서도 볼 수 있습니다. 연결할 수 있는 일정은 기존 항목의 날짜를 바꾸고, 취소는 달력에서 날짜를 빼고 목록에 **대화방 취소**로 남깁니다.

대화 분석은 PC에서 실행하는 규칙을 사용합니다. 명확한 표현을 중심으로 잡으므로 맥락이 모호하거나 규칙에 없는 표현은 빠질 수 있습니다. 원문은 PC의 방별 기록에만 둡니다. 처음 기준을 잡을 때 지문만 저장한 예전 글은 맥락으로 읽을 수 없습니다.

## 연결과 저장

첫 실행에서 `data/settings.json`과 `data/tasks.json`을 만든다. 수집기 위치가 다르면 앱을 닫고 `settings.json`의 `inboxDir`을 브리티 수집기의 `inbox` 경로로 바꾼다. 앱은 30초마다 수집기 폴더의 쪽지 파일을 다시 읽는다(브리티는 자동 갱신 주기에만 건드린다). 수집기의 실행이나 종료는 기존 방식대로 한다.

배포판을 처음 열면 AI 연결과 자동 분류는 꺼져 있다. 일반판의 권장 방식은 **개인 OpenAI API 키 · Luna**다. **Claude Code CLI · Haiku**와 **Codex CLI**도 고를 수 있다. 설정에서 **연결 시험 및 저장**을 누르면 가상 쪽지 한 건으로 시험한다. API 키는 Windows 사용자 계정으로 암호화해 이 PC에 저장한다.

연결 시험에 성공하면 **새 쪽지 자동 분류**가 켜진다. 자동 분류와 **다듬기**에서 쪽지 본문과 인용된 이전 쪽지가 선택한 AI로 전달되며, 본문에 포함된 개인정보도 전달될 수 있다. 첨부 파일은 PC에 남는다. 자동 분류는 설정에서 끌 수 있다.

`data/`에는 업무 목록과 설정이 들어간다. 기존 업무 카드와 첨부 사본이 있으면 이곳에서 찾을 수 있다. 이 폴더는 Git에서 제외한다.

새로 수집한 첨부는 Windows의 **다운로드** 폴더에 바로 복사한다. 설정의 **첨부 저장 폴더**에서 다른 폴더를 고를 수 있고, 고른 폴더를 쓸 수 없으면 기본 다운로드 폴더에 저장하고 설정 화면에 알린다. 폴더를 바꿔도 이미 복사한 첨부는 원래 자리에서 연다. 이름이 겹치면 새 파일에 번호를 붙인다. 캘린더에서 **폴더 열기**를 누르면 그 위치를 볼 수 있다. 사본을 찾을 수 없으면 수집기에 저장된 첨부 위치를 연다.

## 백업과 되돌리기

설정의 **백업 만들기**는 업무 목록·설정·정리 기준·대화방 기록(`data`)과 받은 쪽지·첨부(수집기 `inbox`)를 ZIP 하나로 저장한다. API 키와 이 PC의 폴더 경로는 넣지 않는다. 쪽지 원문이 들어 있으므로 학교 밖으로 보내지 않는다. **백업에서 되돌리기**는 지금 자료를 먼저 `data/되돌리기 전 백업/`에 ZIP으로 떠 둔 뒤 백업 내용으로 바꾼다. 다른 AI 방식으로 연결돼 있으면 AI 연결을 끄고 다시 연결하게 한다. 되돌린 쪽지는 첨부를 다시 복사하거나 AI로 다시 보내지 않는다.

정리 기준(`data/정리-기준.md`)은 앱의 새 판과 비교한다. 설치 뒤 고치지 않았으면 새 판으로 바로 바꾸고, 고친 흔적이 있으면 설정에서 바꿀지 묻는다. 바꾸면 고친 파일은 `정리-기준.내가-고친-날짜.md`로 남는다.

## 판과 업데이트

새 ZIP은 배포한 곳에서 받는다. 새 폴더로 옮길 때는 기존 설치에서 **백업 만들기**를 사용하고, 새 설치에서 **백업에서 되돌리기**를 선택한다. 배포처에서 앱 업데이트를 제공하면 머리줄에 새 판 알림이 뜬다.

설정의 **바탕 화면에 바로 가기 만들기**로 캘린더 실행기를 바탕 화면에 추가할 수 있다.

## 지난 쪽지 불러오기

설정의 **지난 쪽지 불러오기**에서 시작일·끝일을 고르고 **몇 건인지 보기**를 누르면, 브리티 쪽지 목록에 지금 보이는 쪽지 가운데 그 기간에 드는 수를 센다(쪽지는 열지 않음). **불러오기**는 그 쪽지를 읽음 여부와 관계없이 20건씩 열어 저장한다(`collect-notes.ps1 -From -To`, 이미 받은 쪽지는 건너뜀). 2026-11-12 실측으로 접근성 목록에는 처음 10건만 보이고 날짜는 월·일만 있어, 오래된 쪽지는 닿지 않을 수 있고 연도는 오늘보다 늦지 않은 해로 본다(`collector/list-date.ps1`). 불러온 쪽지는 첨부를 다운로드 폴더로 복사하지 않고, 자동 분류하지 않는다. 건수와 예상 비용을 보여 주고 확인을 받은 뒤 분류하며, 불러온 날보다 앞선 "까지"는 끝낸 것으로 넣는다(확인 필요인 쪽지는 선생님이 정함).
