브리티 메신저 캘린더 · Claude로 연결하기

Claude 구독(Pro 이상)이 있으면 Claude Code의 Haiku 모델로 쪽지를 정리할 수 있습니다. 보통은 앱이 설치와 로그인을 안내해 줍니다. 이 안내서는 자동 설치가 안 될 때 직접 하는 방법입니다.

0먼저 알아 두기

필요한 것
Claude Pro 이상 구독(무료 플랜은 안 됩니다), Windows 10 이상, 인터넷
비용
구독 안에서 씁니다. 따로 돈이 나가지 않고 구독 사용 한도에서 빠집니다. 한도에 닿으면 풀릴 때까지 정리가 멈춥니다.
관리자 권한
필요 없습니다. 내 Windows 사용자 폴더(C:\Users\내이름\.local\bin)에 설치됩니다.
이미 있으면
Claude 데스크톱 앱이 깔려 있으면 그 안에 Claude Code가 들어 있어 설치가 필요 없습니다. 로그인만 한 번 하면 됩니다.

꼭 확인하세요. 연결하면 쪽지 본문이 Anthropic(Claude)으로 전송됩니다. 첨부 파일은 보내지 않고 PC에 남습니다. 학교·교육청 지침에 맞는지 먼저 확인해 주세요.

1보통은 이렇게 됩니다

  1. 캘린더 설정 → AI 연결 방식에서 Claude Code CLI · Haiku (Claude 구독)를 고릅니다.
  2. 연결 시험 및 저장을 누릅니다.
  3. Claude Code가 없으면 “지금 설치할까요?”가 뜹니다. 설치를 누르고 1~2분 기다립니다.
  4. 로그인 창(검은 창)이 뜨면 안내대로 로그인합니다(아래 3번). 다 되면 그 창을 닫습니다.
  5. 캘린더가 자동으로 다시 시험하고 “연결 시험을 통과했습니다”가 나오면 끝입니다.

이 중 어디에서 막혔는지에 따라 아래 2번(설치) 또는 3번(로그인)을 따라 하세요.

2설치가 안 될 때: 직접 설치하기

방법 가. PowerShell에 한 줄 붙여 넣기 (권장)

  1. 캘린더 설정에서 설치 명령 복사를 누릅니다. (또는 아래 줄을 직접 복사합니다.)
    irm https://claude.ai/install.ps1 | iex
  2. 키보드의 Windows 키를 누르고 PowerShell을 입력한 뒤 Windows PowerShell을 엽니다. 파란 창에 PS C:\Users\…>가 보이면 맞습니다.
  3. 창 안에서 마우스 오른쪽 단추를 누르면 붙여 넣어집니다. Enter를 누릅니다.
  4. 1~2분 동안 아무것도 안 보여도 기다립니다. 다시 PS C:\…>가 나오면 끝난 것입니다.
  5. 확인: PowerShell 창을 새로 열고 claude --version을 입력합니다. 숫자(예: 2.1.321)가 나오면 설치된 것입니다.

방법 나. 명령 프롬프트(CMD)에서

PowerShell이 막혀 있으면 Windows 키 → cmd → 명령 프롬프트를 열고 아래 줄을 붙여 넣습니다.

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

방법 다. winget으로

PowerShell에서 winget install Anthropic.ClaudeCode. 이 방법은 자동 업데이트가 안 되므로 가끔 winget upgrade Anthropic.ClaudeCode를 실행합니다.

방법 라. Claude 데스크톱 앱 설치

claude.com/download에서 Windows용 Claude 앱을 설치합니다. 앱 안에 Claude Code가 들어 있어 캘린더가 알아서 찾습니다. 설치한 뒤 3번 로그인으로 갑니다.

3로그인이 안 될 때: 직접 로그인하기

  1. 캘린더 설정에서 로그인 창 열기를 누릅니다. 창이 안 뜨면 PowerShell을 열고 claude를 입력합니다.
  2. 처음이면 글자 색(테마)을 고르라고 합니다. 아무거나 고르고 Enter.
  3. 로그인 방법을 물으면 Claude account with subscription(Claude 구독 계정)을 고릅니다. 질문 없이 입력 칸만 보이면 /login을 입력합니다.
  4. 브라우저가 열리면 평소 쓰는 Claude 계정으로 로그인하고 승인을 누릅니다.
  5. 창으로 돌아와 로그인됐다고 나오면 /exit를 입력하거나 창을 닫습니다.
  6. 캘린더에서 연결 시험 및 저장을 다시 누릅니다.

Claude 데스크톱 앱에 로그인돼 있어도 Claude Code 로그인은 따로 한 번 해야 합니다.

4이런 글이 보이면

“'irm'은(는) 내부 또는 외부 명령… 아닙니다”명령 프롬프트(CMD)에 PowerShell 명령을 넣었습니다. PowerShell을 열어 다시 하거나 방법 나를 씁니다.
“'&&' 토큰은 올바른 문 구분 기호가 아닙니다”PowerShell에 CMD 명령을 넣었습니다. 명령 프롬프트를 열어 다시 하거나 방법 가를 씁니다.
“403”, “원격 서버에 연결할 수 없습니다”, 아무 반응 없이 끝남학교망이나 보안 프로그램이 내려받기를 막았을 수 있습니다. 정보 담당자에게 claude.ai 접속과 Claude Code 설치가 가능한지 물어보세요. 집이나 다른 망에서 설치해도 됩니다.
보안 프로그램이 “차단”, “위험” 창을 띄움학교 보안 프로그램의 정책입니다. 임의로 끄지 말고 정보 담당자에게 문의하세요.
“claude을(를) 찾을 수 없습니다”설치 직후에는 새 창을 열어야 인식됩니다. 캘린더는 설치 위치를 직접 찾으므로 캘린더에서 바로 연결 시험을 눌러도 됩니다.
“로그인되어 있지 않습니다”3번 로그인을 합니다.
“무료 플랜” 또는 접근할 수 없다는 글Claude Code는 Pro 이상 구독에서만 됩니다.
“사용 한도에 닿았습니다”구독 한도가 풀릴 때까지 기다리거나, 그동안 다른 연결 방식을 씁니다.

5그래도 안 되면

  • API 키 방식(개인 OpenAI API 키 · Luna)으로 연결합니다. 설치가 필요 없고 키만 붙여 넣으면 됩니다. 같은 폴더의 AI-SETUP.txt와 API-연결-안내.html을 보세요.
  • AI 없이도 쪽지 가져오기와 달력은 그대로 쓸 수 있습니다. 정리만 손으로 합니다.

설치 명령은 Claude Code 공식 안내(code.claude.com/docs/en/setup, 2026년 11월)를 따랐습니다. Anthropic이 명령을 바꾸면 그 안내를 따르세요. 이 앱은 Anthropic이나 브리티의 공식 프로그램이 아닙니다.
