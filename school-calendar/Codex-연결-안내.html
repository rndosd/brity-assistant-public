브리티 메신저 캘린더 · Codex로 연결하기

ChatGPT 구독이 있으면 OpenAI의 Codex CLI로 쪽지를 정리할 수 있습니다. API 키를 따로 만들 필요가 없습니다. 보통은 앱이 설치와 로그인을 이어서 해 줍니다. 이 안내서의 2번·3번은 자동으로 안 될 때 직접 하는 방법입니다.

0먼저 알아 두기

필요한 것
Codex를 쓸 수 있는 ChatGPT 구독(공식 안내 기준 Plus·Pro·Business·Edu·Enterprise), Windows 10 이상, 인터넷
비용
구독 안에서 씁니다. 따로 돈이 나가지 않고 구독의 Codex 사용 한도에서 빠집니다. 한도에 닿으면 풀릴 때까지 정리가 멈춥니다.
모델
Codex는 ChatGPT 계정의 기본 모델로 정리합니다. 이 앱이 시험한 Luna보다 상위 모델이 쓰일 수 있어, 따로 돈은 나가지 않지만 구독 한도가 더 빨리 줄 수 있습니다.
이미 있으면
Codex 데스크톱 앱이 깔려 있으면 그 안에 든 Codex를 캘린더가 알아서 찾습니다. 따로 설치하지 않고 1번부터 해 보세요.

AI가 읽는 것 · 쪽지를 정리할 때 OpenAI의 AI가 쪽지 본문을 읽고 날짜와 할 일을 뽑습니다. 학습에 쓰일지는 ChatGPT 계정의 데이터 설정을 따릅니다. 첨부 파일은 보내지 않습니다.

1캘린더에서 연결하기

  1. 캘린더 설정 → AI 연결 방식에서 Codex CLI (ChatGPT 구독)를 고릅니다.
  2. 연결 시험 및 저장을 누릅니다.
  3. Codex가 없으면 “지금 설치할까요?”가 뜹니다. 설치를 누르고 1~2분 기다립니다. OpenAI 공식 설치 명령을 쓰고, 관리자 권한은 필요 없습니다.
  4. 로그인이 안 돼 있으면 검은 창과 브라우저가 열립니다. 브라우저에서 평소 쓰는 ChatGPT 계정으로 로그인하고 허용을 누르면 창이 저절로 닫힙니다.
  5. 캘린더가 바로 가짜 쪽지 한 건으로 다시 시험하고, “연결 시험을 통과했습니다”가 나오면 끝입니다. 새 쪽지 자동 분류가 켜집니다.

설치나 로그인에서 막히면 아래 2번(설치)과 3번(로그인)을 직접 한 뒤 다시 누르세요.

2Codex 설치하기

방법 가. PowerShell에 한 줄 붙여 넣기 (권장)

  1. 아래 줄을 복사합니다.
    powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
  2. 키보드의 Windows 키를 누르고 PowerShell을 입력한 뒤 Windows PowerShell을 엽니다. 파란 창에 PS C:\Users\…>가 보이면 맞습니다.
  3. 창 안에서 마우스 오른쪽 단추를 누르면 붙여 넣어집니다. Enter를 누르고, 다시 PS C:\…>가 나올 때까지 기다립니다.
  4. 확인: PowerShell 창을 새로 열고 codex --version을 입력합니다. codex-cli와 숫자가 나오면 설치된 것입니다.

방법 나. npm으로 (Node.js가 이미 있으면)

npm install -g @openai/codex

이름이 그냥 codex인 다른 npm 패키지가 있습니다. 꼭 @openai/codex를 쓰세요.

방법 다. Codex 데스크톱 앱 설치

chatgpt.com/codex에서 Windows용 Codex 앱을 설치합니다. 캘린더가 앱 안의 Codex를 찾습니다. 설치한 뒤 3번 로그인으로 갑니다.

3ChatGPT 계정으로 로그인하기

  1. PowerShell을 열고 codex login을 입력합니다.
  2. 브라우저가 열리면 평소 쓰는 ChatGPT 계정으로 로그인하고 허용합니다. (Sign in with ChatGPT)
  3. 창에 로그인됐다고 나오면 닫습니다. 확인하려면 codex login status를 입력합니다.
  4. 캘린더에서 연결 시험 및 저장을 다시 누릅니다.

Codex 데스크톱 앱만 쓰는 경우, 앱에서 로그인했어도 연결 시험이 실패하면 위 순서로 한 번 더 로그인해 주세요.

4이런 글이 보이면

“Codex에서 정리를 받지 못했습니다. CLI 로그인 상태와 버전을…”설치(2번)와 로그인(3번)을 확인합니다. 둘 다 했다면 codex --version으로 너무 오래된 판이 아닌지 보고, 방법 가를 다시 실행해 새 판으로 바꿉니다.
“'codex'은(는) 내부 또는 외부 명령… 아닙니다”, “codex을(를) 찾을 수 없습니다”설치 직후에는 새 창을 열어야 인식됩니다. 캘린더는 설치 위치를 직접 찾으므로 캘린더에서 바로 연결 시험을 눌러도 됩니다.
“AI 정리가 90초 안에 끝나지 않았습니다”인터넷이 느리거나 Codex 서버가 바쁜 때입니다. 잠시 뒤 다시 누릅니다.
“403”, “원격 서버에 연결할 수 없습니다”, 아무 반응 없이 끝남학교망이나 보안 프로그램이 내려받기를 막았을 수 있습니다. 정보 담당자에게 chatgpt.com 접속과 Codex 설치가 가능한지 물어보세요.
보안 프로그램이 “차단”, “위험” 창을 띄움학교 보안 프로그램의 정책입니다. 임의로 끄지 말고 정보 담당자에게 문의하세요.
사용 한도·요금제 관련 글구독의 Codex 한도가 풀릴 때까지 기다리거나, 그동안 다른 연결 방식을 씁니다.

5그래도 안 되면

  • API 키 방식(개인 OpenAI API 키 · Luna)으로 연결합니다. 설치가 필요 없고 키만 붙여 넣으면 됩니다. OpenAI 연결 안내를 보세요. ChatGPT 구독과 API 사용료는 따로 청구됩니다.
  • Claude 구독이 있으면 Claude Code CLI로도 연결할 수 있습니다(Claude 구독 연결 안내).
  • 연결이 될 때까지 쪽지는 날짜 없이 제목 그대로 할 일에 들어갑니다. 나중에 연결하면 목록 위 AI로 정리로 한꺼번에 정리할 수 있습니다.

설치·로그인 명령은 Codex CLI 공식 안내(github.com/openai/codex, 2026년 11월)를 따랐습니다. OpenAI가 명령을 바꾸면 그 안내를 따르세요. 이 앱은 OpenAI나 브리티의 공식 프로그램이 아닙니다.
