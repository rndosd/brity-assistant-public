브리티 쪽지가 오면 AI가 짧은 제목·날짜·할 일을 알아서 정리해 달력에 올려 줍니다. 이 안내대로 한 번만 설정하면 됩니다. 10분 정도 걸립니다.

0먼저 알아 두기

안 해도 됩니다
AI 없이도 쪽지 가져오기·달력·지시문 복사는 다 됩니다. 정리를 손으로 할지 AI에 맡길지의 차이입니다.
비용
사용량은 연결한 API 계정에 청구됩니다. 결제 화면에서 해당 계정의 요금과 잔액을 확인하세요.
준비물
API 키를 만들 수 있는 OpenAI 개발자 계정과 해당 계정의 결제 설정

연결 전에 확인하세요. 연결이 성공하면 자동 분류가 켜집니다. 분류할 때 쪽지 본문과 인용된 이전 쪽지가 OpenAI로 전달되며, 본문에 포함된 개인정보도 전달될 수 있습니다. 첨부 파일은 PC에 남습니다. 소속 기관의 기준을 확인한 뒤 연결하세요.

1OpenAI 개발자 화면에 로그인

  1. platform.openai.com에 들어갑니다. ChatGPT와 같은 계정으로 로그인할 수 있습니다.
  2. 처음이면 이름·생년월일 같은 기본 정보를 넣고 가입을 마칩니다.

화면은 영어로 나옵니다. 아래 안내의 영어 단추 이름을 찾아 누르면 됩니다. OpenAI가 화면을 바꾸면 이름이 조금 다를 수 있습니다.

2결제 설정 확인

캘린더 앱 설정 → AI 연결 방식에서 개인 OpenAI API 키 · Luna를 고르면 나오는 API 결제 설정 ↗을 누르면 결제 화면이 바로 열립니다.

  1. API 프로젝트의 잔액과 사용 가능 상태를 확인합니다.
  2. 결제 정보나 충전이 필요하면 현재 화면의 안내에 따라 설정합니다. 결제 전 금액과 자동 충전 여부를 확인하세요.

3API 키 만들기

앱의 API 키 발급 ↗을 누르면 키 화면이 열립니다.

  1. Create new secret key를 누릅니다.
  2. 이름은 알아보기 쉽게 브리티 메신저 캘린더라고 적고 만듭니다.
  3. sk-로 시작하는 긴 글자를 바로 복사합니다. 이 화면을 닫으면 다시 볼 수 없습니다. 잃어버리면 새로 만들면 됩니다.

키는 비밀번호와 같습니다. 메신저·메일로 남에게 보내거나 문서에 붙여 두지 마세요. 키를 가진 사람은 내 충전금으로 AI를 쓸 수 있습니다.

4앱에 키 넣고 연결 시험

  1. 캘린더 앱 설정을 엽니다.
  2. AI 연결 방식에서 개인 OpenAI API 키 · Luna를 고릅니다.
  3. OpenAI API 키 칸에 복사한 키를 붙여 넣습니다(Ctrl+V).
  4. 연결 시험 및 저장을 누릅니다. 가짜 쪽지 한 건으로 시험합니다.
  5. 연결 시험을 통과했습니다가 나오면 성공입니다. 키는 이 Windows 계정에서만 풀 수 있게 암호화해 저장됩니다.

5자동 분류 설정

  1. 연결에 성공하면 새 쪽지 자동 분류가 켜집니다. 자동으로 분류할 필요가 없으면 같은 설정 화면에서 끕니다.
  2. 새로 들어오는 쪽지를 할 일·알아 둘 것·숨긴 것으로 정리하며, 날짜가 있는 항목은 달력에서 볼 수 있습니다.
  3. 이미 들어와 있던 쪽지는 자동으로 정리되지 않습니다. 업무를 눌러 오른쪽 다듬기를 누르면 정리됩니다.
  4. AI가 잘못 나눈 쪽지는 상세 화면에서 분류와 날짜를 고칠 수 있습니다.

“사용 한도에 도달했습니다”충전이 안 됐거나 잔액이 0입니다. 결제 화면에서 잔액을 확인하고 충전하세요. 다시 눌러 보기만 해서는 풀리지 않습니다.
“요청을 거절했습니다”키가 해당 프로젝트의 요청을 보낼 수 있는지와 모델 사용 권한을 확인하세요.
