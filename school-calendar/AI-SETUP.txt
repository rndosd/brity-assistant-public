브리티 메신저 캘린더를 다른 Windows PC에서 쓰기
이 프로그램은 브리티 메신저의 공식 기능이 아니라 개인이 만든 비공식 도구입니다(삼성SDS·교육청과 관계없음).
처음 시작하는 순서는 같은 폴더의 처음-시작-안내.html에 차례대로 정리돼 있습니다.

1. ZIP 전체를 쓰기 가능한 폴더(예: 문서)에 풉니다. ZIP 안에서 바로 실행하지 않습니다.
2. Brity-Messenger-Calendar 폴더의 Brity Messenger Calendar.exe를 엽니다. Node.js 설치는 필요 없습니다.
3. 먼저 AI를 연결합니다(1단계). 앱 위쪽의 ‘AI 연결’을 누르면 설정의 AI 탭이 열립니다. 방법은 아래 ‘AI 연결’을 보세요.
4. 브리티 메신저에 로그인한 뒤 앱 위쪽의 ‘브리티 연결’을 누릅니다(2단계). 가져온 쪽지는 브리티에서 읽음 처리됩니다. 연결한 뒤에는 같은 자리의 ‘쪽지 가져오기’로 바로 가져오고, 캘린더가 열려 있는 동안 설정의 자동 갱신 주기(기본 1시간)마다 새 쪽지를 확인합니다.

새로 가져온 쪽지의 첨부는 이 PC의 ‘다운로드’ 폴더에 저장됩니다. 같은 이름의 파일이 있으면 번호를 붙입니다. 쪽지 상세의 ‘폴더 열기’로도 볼 수 있습니다.

AI 연결 (설정 → AI)

쪽지에서 날짜와 할 일을 뽑아 달력에 올리는 일을 AI가 합니다. AI 없이 브리티부터 연결하면 쪽지가 날짜 없이 제목 그대로 할 일에 쌓입니다. 나중에 AI를 연결하면 목록 위 ‘AI로 정리’로 한꺼번에 정리할 수 있습니다.

• 개인 OpenAI API 키 · Luna (권장)
  같은 폴더의 API-연결-안내.html(가입·충전·키 발급·연결 순서, 비용, 주의할 점)을 따라 본인 계정으로 준비합니다. 사용량은 각자 API 계정에 청구됩니다.
  설정의 ‘내 역할’(학년·반·담임·담당 업무)을 적어 두면 분류가 더 정확해집니다.
• 다른 방법 1: 개인 Claude API 키 · Haiku
  OpenAI 대신 Anthropic(Claude) 개발자 계정으로 키를 만들어 붙여 넣습니다. 같은 폴더의 Claude-API-연결-안내.html(가입·충전·키 발급·연결 순서)을 따라 하세요. 사용량은 그 API 계정에 청구됩니다. Claude 구독과는 별개입니다.
• 다른 방법 2: Claude Code CLI · Haiku (Claude 구독, Pro 이상)
  Claude 데스크톱 앱이 깔려 있으면 따로 설치하지 않아도 됩니다. 없으면 ‘연결 시험 및 저장’이 설치할지 묻습니다. 직접 설치하려면 PowerShell에 irm https://claude.ai/install.ps1 | iex 를 붙여 넣습니다.
  ‘연결 시험 및 저장’을 누르면 없을 때 설치할지 묻고, 로그인이 필요하면 로그인 창과 브라우저를 엽니다. 브라우저에서 로그인하고 승인하면 창이 저절로 닫히고 바로 다시 시험합니다.
  자동 설치나 로그인이 안 되면 같은 폴더의 Claude-연결-안내.html을 따라 하세요. 사용량은 각자 Claude 구독 한도에서 나갑니다.
• 다른 방법 3: Codex CLI (ChatGPT 구독)
  이 방법을 고르고 ‘연결 시험 및 저장’을 누릅니다. API 키는 필요 없습니다. Codex가 없으면 설치할지 묻고(OpenAI 공식 설치 명령), 로그인이 안 돼 있으면 ChatGPT 로그인 창을 엽니다. 로그인을 마치면 바로 다시 시험합니다.
  자동 설치나 로그인이 안 되면 같은 폴더의 Codex-연결-안내.html을 따라 하세요(설치 한 줄 → codex login). 사용량은 각자 ChatGPT 구독 한도에서 나갑니다.

모델: 쪽지 정리에는 Luna(OpenAI)·Haiku(Claude)를 씁니다. 이 앱이 시험을 마친 모델이고, 쪽지마다 부르기 때문에 비용을 낮추려고 고정해 두었습니다. Codex는 ChatGPT 계정의 기본 모델로 돌아 이보다 상위 모델이 쓰일 수 있고, 그만큼 구독 한도가 더 빨리 줄 수 있습니다.

연결 시험에는 가짜 쪽지를 씁니다. 연결이 성공하면 자동 분류가 켜집니다. API 키는 이 Windows 계정에서 암호화해 저장합니다. AI 분류를 실행하면 쪽지 본문과 인용된 이전 쪽지가 선택한 AI로 전달되며 첨부 파일은 PC에 남습니다. 본문에 포함된 개인정보도 전달될 수 있으므로 연결 전에 소속 기관의 기준을 확인하세요. 자동 분류는 설정에서 끌 수 있습니다.

연결이 막혔을 때

• 브리티를 연결할 때는 브리티에 로그인한 뒤 ‘브리티 연결’을 누릅니다. 브리티를 닫았다 다시 열면 캘린더가 다음 확인 때 다시 연결을 시도합니다. 브리티를 쓰는 중이면 가져오기 전에 묻습니다(자동 갱신 때는 Windows 알림). 쪽지가 읽히지 않으면 브리티 창을 한 번 열어 줍니다.
• 브리티 첨부 다운로드 폴더를 바꿨다면, 실제 위치를 확인한 뒤 collector\labels.json의 downloadDir만 바꿉니다.
• 가상 업무로 먼저 둘러보려면 Brity Messenger Calendar Sample.exe를 엽니다. 샘플은 실제 업무와 따로 저장됩니다.
• 압축을 푼 Brity-Messenger-Calendar 폴더에서 앱 자료(설정·업무)는 calendar-data에, 가져온 쪽지는 collector\inbox에 저장됩니다.
