브리티 메신저 캘린더를 다른 Windows PC에서 쓰기
이 프로그램은 브리티 메신저의 공식 기능이 아니라 개인이 만든 비공식 도구입니다(삼성SDS·교육청과 관계없음).

1. ZIP 전체를 쓰기 가능한 폴더(예: 문서)에 풉니다. ZIP 안에서 바로 실행하지 않습니다.
2. 브리티 메신저에 로그인한 상태에서 Brity-Messenger-Calendar 폴더의 Brity Messenger Calendar.exe를 엽니다. Node.js 설치는 필요 없습니다.
3. 앱 위쪽의 ‘브리티 연결’을 누릅니다. 가져온 쪽지는 브리티에서 읽음 처리됩니다. 연결한 뒤에는 같은 자리의 ‘쪽지 가져오기’로 바로 가져오고, 캘린더가 열려 있는 동안 설정의 자동 갱신 주기(기본 1시간)마다 새 쪽지를 확인합니다.

새로 가져온 쪽지의 첨부는 이 PC의 ‘다운로드’ 폴더에 저장됩니다. 같은 이름의 파일이 있으면 번호를 붙입니다. 쪽지 상세의 ‘폴더 열기’로도 볼 수 있습니다.

AI 자동 분류 연결 (설정)

수집과 달력은 AI 없이도 바로 쓸 수 있습니다. 쪽지를 할 일·알아 둘 것으로 자동 분류하려면 설정에서 AI를 연결합니다.

• 개인 OpenAI API 키 · Luna (권장)
  같은 폴더의 API-연결-안내.html(가입·충전·키 발급·연결 순서, 비용, 주의할 점)을 따라 본인 계정으로 준비합니다. 사용량은 각자 API 계정에 청구됩니다.
  설정의 ‘내 역할’(학년·반·담임·담당 업무)을 적어 두면 분류가 더 정확해집니다.
• 다른 방법 1: Claude Code CLI · Haiku (Claude 구독, Pro 이상)
  Claude 데스크톱 앱이 깔려 있으면 따로 설치하지 않아도 됩니다. 없으면 설정의 ‘설치 명령 복사’를 누르고 PowerShell에 붙여 넣어 설치합니다(irm https://claude.ai/install.ps1 | iex).
  ‘연결 시험 및 저장’을 누르면 없을 때 설치할지 묻고, 로그인이 필요하면 로그인 창을 엽니다. 창을 닫으면 자동으로 다시 시험합니다.
  자동 설치나 로그인이 안 되면 같은 폴더의 Claude-연결-안내.html을 따라 하세요. 사용량은 각자 Claude 구독 한도에서 나갑니다.
• 다른 방법 2: Codex CLI (ChatGPT 구독)
  Codex CLI에 로그인된 PC라면 이 방법을 고르고 ‘연결 시험 및 저장’을 누릅니다. 설치와 로그인 안내: https://learn.chatgpt.com/docs/codex/cli

연결 시험에는 가짜 쪽지를 씁니다. 연결이 성공하면 자동 분류가 켜집니다. API 키는 이 Windows 계정에서 암호화해 저장합니다. AI 분류를 실행하면 쪽지 본문과 인용된 이전 쪽지가 선택한 AI로 전달되며 첨부 파일은 PC에 남습니다. 본문에 포함된 개인정보도 전달될 수 있으므로 연결 전에 소속 기관의 기준을 확인하세요. 자동 분류는 설정에서 끌 수 있습니다.

연결이 막혔을 때

• 처음 연결할 때는 브리티에 로그인한 뒤 ‘브리티 연결’을 누릅니다. 브리티를 닫았다 다시 열면 캘린더가 다음 확인 때 다시 연결을 시도합니다. 브리티를 쓰는 중이면 가져오기 전에 묻습니다(자동 갱신 때는 Windows 알림). 쪽지가 읽히지 않으면 브리티 창을 한 번 열어 줍니다.
• 브리티 첨부 다운로드 폴더를 바꿨다면, 실제 위치를 확인한 뒤 collector\labels.json의 downloadDir만 바꿉니다.
• 가상 업무로 먼저 둘러보려면 Brity Messenger Calendar Sample.exe를 엽니다. 샘플은 실제 업무와 따로 저장됩니다.
• 압축을 푼 Brity-Messenger-Calendar 폴더에서 앱 자료(설정·업무)는 calendar-data에, 가져온 쪽지는 collector\inbox에 저장됩니다.
